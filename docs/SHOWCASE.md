## Short project description (resume / portfolio)

**CropCast AI | Machine Learning Crop Yield Prediction Web App**  
Built and publicly deployed a Python/Streamlit application that loads a trained scikit-learn Random Forest pipeline to estimate crop yield from eight environmental and agricultural inputs. Added interactive inputs, reproducible model evaluation, visual diagnostics, model-integrity verification and CSV exports. On an internal 10,000-row random test split, Model B achieved R² = 0.9031 and RMSE = 0.5233 t/ha; independent real-farm validation remains future work.

## Project post (optional public announcement)

🌾 **CropCast AI — now live!**

I built and deployed a crop-yield prediction prototype using Python, Streamlit and Random Forest Regression. Users can explore crop, soil, rainfall, temperature and farming scenarios, get a model-generated estimate and download results as CSV.

The deployed model was evaluated on a 10,000-row random test set (R²: 0.9031, RMSE: 0.5233 t/ha). These are experimental dataset results—not independently validated farm forecasts.

Live demo: https://cropcast-yield-ai.streamlit.app/  
Source code: https://github.com/Kxni5hk/crop-yield-predictor

My next priorities are data provenance, independent validation, explainability and weather-aware scenarios.
